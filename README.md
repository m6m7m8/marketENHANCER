# MARKET ENHANCER

Userscript для удобной работы с [LZT Market](https://lzt.market): поиск редких предметов на аккаунтах, подсветка ценных лотов, автоназвания, расчёт цен, статистика профита и автопубликация лотов на FunPay.

Скрипт работает прямо в браузере через Tampermonkey и добавляет поверх LZT Market удобную панель инструментов для продавцов, перекупов и людей, которые регулярно оценивают аккаунты.

## Для кого это

- **Продавцам** — быстрее оформлять лоты, собирать названия из редких предметов, видеть редкие скины и дни активности.
- **Перекупам** — быстро оценивать аккаунты, смотреть примерную цену редких предметов, считать профит за день/неделю/месяц.
- **Тем, кто работает с FunPay** — ставить лоты в очередь публикации, автоматически переносить название, описание, картинки и параметры.
- **Тем, кто ищет редкие аккаунты** — подсветка нужных скинов, предметов, игр, медалей, танков, персонажей и бойцов прямо на странице товара.


## Что умеет

**Поиск редких предметов.** Скрипт находит нужные предметы на странице аккаунта и выводит их отдельным красивым блоком. Поддерживаются Valorant, Fortnite, League of Legends, Steam, CS2-медали, Genshin Impact, Honkai: Star Rail, Zenless Zone Zero, World of Tanks, Rainbow Six Siege и Brawl Stars. Порядок предметов в настройках задаётся перетаскиванием. Чем выше предмет в списке, тем выше он будет показан в блоке, автоназвании и FunPay-лоте. Для каждого редкого предмета можно задать цвет и эффект: обычный, glow, fire или shimmer. Эффекты применяются и к карточкам, и к бейджам активности.

**Автоназвание.** Скрипт может собрать название лота из количества предметов и найденных редких. Например: `154 skins / GALAXY, IKONIK, BLACK KNIGHT`. Название автоматически урезается под лимит LZT. Учитывается также приоритет первых редких выбранный вами.

**Дни активности.** На странице товара рядом с последней активностью добавляется понятный бейдж с количеством дней. Цвет зависит от настроенных диапазонов.

**Дни с публикации.** В категориях маркета скрипт показывает, сколько дней назад был опубликован лот. На главной странице LZT эта функция отключена, потому что там смешаны разные категории.

**Цены редких предметов.** Скрипт через API ищет похожие аккаунты и показывает минимальную/среднюю цену и количество найденных аккаунтов с ТАКОЙ ЖЕ ОТЛЕГОЙ. Для Valorant учитывается также регион.

**CS2-инвентарь через market.csgo.com.** Скрипт считает стоимость CS2-инвентаря по ценам market.csgo.com, показывает найденные цены по предметам и процент разницы относительно стоимости именно CS2-инвентаря.

**FunPay Uploader.** Публикует товар со скринами скинов за 10 секунд. Название, описание, картинки и параметры, ставит задачу в очередь и создаёт лот на FunPay.

**История публикаций.** Скрипт хранит локальную историю публикаций: статус, время, игру, название, ссылку на FunPay и ссылку на LZT.

**Статистика профита.** Во вкладке статистики показывается прибыль за день, 7 дней и месяц: продажи минус покупки по истории платежей LZT.

**Кастомизация.** Есть темы, палитры, цвета, импорт/экспорт настроек, готовые базы редких предметов и настройка диапазонов активности.

## Поддерживаемые категории

**Valorant.**
Ищет редкие скины оружия и брелки. Есть готовая база Champions, Arcane, VCT и других редких предметов.

**Fortnite.**
Ищет редкие скины, кирки, эмоции, планеры и другие предметы. В базе есть GALAXY, IKONIK, BLACK KNIGHT, Travis Scott, OG Skull Trooper, OG Ghoul Trooper и другие.

**League of Legends.**
Ищет редкие скины.

**Genshin Impact, Honkai: Star Rail, Zenless Zone Zero.**
Ищет нужных персонажей miHoYo. Дополнительно можно включить фильтр по уровню персонажа.

**Steam.**
Ищет нужные игры в списке игр аккаунта. Отдельно поддерживаются CS2-медали.

**World of Tanks.**
Ищет нужные танки. 

**Rainbow Six Siege / Ubisoft.**
Ищет скины, например BLACK ICE.

**Brawl Stars.**
Ищет бойцов Supercell с учётом минимальной силы. Например можно искать MICO только от 11 силы.

## FunPay Uploader

FunPay Uploader позволяет создавать лоты FunPay с LZT-страницы.

Поддерживается публикация:

- Fortnite
- Valorant

Для Valorant скрипт подставляет:

- количество скинов
- редкие скины
- количество агентов
- регион
- ранг
- картинки оружия и брелков

Для Fortnite скрипт подставляет:

- количество скинов
- редкие предметы
- картинки скинов, кирок, эмоций и планеров

Шаблоны названий и описаний поддерживают переменные:

- `{count}` — количество предметов
- `{rare}` — список редких предметов

Есть отдельные поля для RU и EN. Для английских названий Valorant кириллица транслитерируется латиницей, потому что FunPay не принимает кириллицу в английском названии.

Важно: публикация на FunPay идёт через текущий браузер и его IP/прокси. Используется `golden_key` из скрипта и куки текущего браузера.

## Цены и оценка аккаунтов

Скрипт умеет показывать плашку цены для редкого предмета:

- минимальная цена
- средняя цена
- количество найденных аккаунтов
- возраст данных

Для поиска похожих аккаунтов используются параметры текущего лота. Например для Valorant учитывается регион аккаунта, а для отлеги используется последняя активность.

Если аккаунтов с такими параметрами не найдено, скрипт предлагает перейти по внешней ссылке и понизить отлегу для более точной оценки.

## CS2-инвентарь

На steam-value страницах скрипт считает стоимость CS2-инвентаря через market.csgo.com.

Показывается:

- общая стоимость по market.csgo.com
- сколько из скольки предметов удалось найти на случай проблем с market.csgo.tm
- цена рядом с каждым предметом на lzt.market/steam-value/
- ссылка на предмет на market.csgo.com
- процент разницы относительно стоимости именно CS2-инвентаря

Если на Steam-аккаунте есть предметы других игр, они не попадают в расчёт CS2-процента.

## Статистика

Во вкладке статистики показывается прибыль:

- за день
- за 7 дней
- за месяц

Профит считается как продажи аккаунтов минус покупки аккаунтов по истории платежей LZT.

Для работы нужен API-токен с правом `payment`.

## Настройки

В меню настроек можно:

- редактировать списки редких предметов
- менять порядок предметов drag-and-drop
- задавать цвет и эффект каждому предмету
- загружать готовую базу редких
- очищать списки
- настраивать уровни активности
- выбирать тему интерфейса
- менять цвета панели и акцентов
- включать/выключать дни с публикации
- включать/выключать расчёт CS2-инвентаря
- импортировать и экспортировать настройки JSON

При экспорте `golden_key` и `API`не сохраняется в файл.

## Установка

1. Установите [Tampermonkey](https://www.tampermonkey.net/).
2. Установите скрипт `market-helper.user.js`.
3. Откройте LZT Market и нажмите кнопку меню скрипта в правом нижнем углу и убедитесь что ее не закрывает окно чата.

## Первый запуск

1. Откройте настройки скрипта.
2. Во вкладке API вставьте LZT API token.
3. Для дней публикации и цен нужен токен с правами `market`.
4. Для статистики профита нужен токен с правами `payment`.
5. Во вкладке Uploader можно добавить `golden_key` FunPay, если нужна публикация на FunPay.
6. Настройте списки редких предметов или загрузите готовые базы.


## Требования

- Tampermonkey
- LZT API token для API-функций
- Право `market` для цен и дней публикации
- Право `payment` для статистики профита
- golden_key FunPay для FunPay Uploader

## Ограничения

- Для полной изоляции FunPay-аккаунтов лучше использовать отдельный браузер/профиль или чистить cookies FunPay.
- market.csgo.com цены зависят от доступности публичного API market.csgo.com.

## Лицензия

Проект распространяется как userscript. Используйте на свой страх и риск.
